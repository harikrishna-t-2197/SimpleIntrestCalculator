# Simple Interest Calculator

A lightweight, dependency-free calculator for estimating simple interest in your
browser.

Enter a principal amount, an annual interest rate, and a time period in years.
The calculator shows the interest and the total amount using:

```text
Simple interest = principal × annual rate × time ÷ 100
Total amount = principal + simple interest
```

## Run locally

Open `index.html` in any modern web browser. No installation or build step is
required.
