# Simple Interest Calculator

A lightweight, browser-based calculator for simple interest. Open `index.html` in
any modern web browser, enter the principal amount, annual interest rate, and
time in years, then select **Calculate interest**.

The calculator uses the formula `I = P × R × T / 100`, where `P` is the
principal, `R` is the annual rate as a percentage, and `T` is the time in
years. It displays the interest earned and the principal plus interest. Values
are shown to two decimal places; no currency is assumed.
